# 交互规范
区分用户硬要求与实施默认；实现默认不是已经播放验证的结果。

## 模特统一编辑（已确认）
进入：人物详情唯一“编辑资料”入口。列表新建创建一个草稿，进入同类编辑器。
- 编辑器分区：基本资料（姓名/别名/简介）；模特头像；详细资料（自定义字段/兴趣备注/排序）；社交链接；关联写真集。档案照片不再提供编辑分区，已有数据保留。背景设置暂时搁置，既有背景数据保持原样。
- 所有分区共享一个草稿；切换分区不会丢失输入，也不立即修改显示页。
- 模特编辑器所有分区统一使用顶部横向导航，正文位于导航下方；基本资料、详细资料、社交链接和关联写真集不再切换为左侧竖栏。新建与编辑使用同一布局，头像裁切与选图内容沿用既有实现。
- 头像分区采用左侧大预览与圆形裁切、右侧照片来源和四列网格。来源为收藏图片、关联写真集及本地选图，不提供全部图片入口；照片直接滚动浏览，原生候选以 48 项窗口按需读取，虚拟网格与缓存保持有界，不显示页码、总项数或跳转输入框。拖动或方向键调整位置，预览区滚轮与滑杆调整 100–300% 缩放；外层编辑区隐藏滚动条，不显示底部操作说明文字。裁切参数保存在 `ModelProfile.avatarCrop`，没有参数的旧数据沿用 `avatarFocus`。各处头像使用同一裁切方式。自定义图片只读引用，选择后先预览，随保存资料一并登记，取消不提交；不生成裁切副本、不修改原件。
- 自定义字段允许增删、标签/值编辑及排序；空的可选字段不强制展示；详情采用分组只读排版。
- 保存统一提交，成功后关闭并更新相关页面；失败保留草稿及错误提示。
- 取消不提交；未保存修改时关闭/Esc 提示是否放弃，未修改时直接关闭。焦点返回“编辑资料”。
- 不在详情增加单独的换背景、加字段、照片删除或关系编辑入口。阅读社交链接/展开信息/打开照片不是编辑操作。

## 写真集封面设置
- 直接在写真集编辑器左侧封面区完成取景与选图，不使用二级窗口或“选择封面”入口；底部采用连续横向缩略图轨道与滚轮选图，不显示左右滚动箭头（2026-10-07 用户明确要求）。原生照片按 48 项窗口读取，渲染与缓存保持有界；不显示组合式分页跳转栏。
- 封面预览占满左侧可用区域，按原图比例完整适应，不使用固定 3:4 裁切框。有图片时不显示预览区灰色底板与外框，空状态保留底板。选图轨道无外框、底色与阴影，缩略图下移贴近预览底部；鼠标进入预览下半部时淡入，离开后淡出。轨道不占正文高度，不改变图片尺寸。键盘聚焦轨道时保持可见，隐藏时不可交互，减少动态效果时直接切换。
- 鼠标停留的缩略图原位放大并出现阴影，图片悬停不显示文件名或操作说明提示；整条轨道仍无阴影。位置与缩放分离，中心不横向偏移、邻居不重排，滚动到末项同样成立；为放大与阴影留出空间。键盘有等价反馈与可访问名称；减少动态效果时停止悬停放大，保留静态反馈。具体倍率和时长为实施默认。依据：已确认的 PREF-005，完整行为记录于本条。
- 预览每次打开或换图均从完整适应开始；原有裁切数据在实际调整前保持不变。保留三分网格、拖动平移与滚轮缩放，不显示缩放滑杆、加减按钮或百分比栏。方向键平移，＋／－键缩放；重置恢复默认封面并完整适应。100–300% 缩放范围为实施默认。
- 选图和取景直接更新写真集编辑草稿，统一由“保存写真集”提交 `Album.coverMediaId` 与 `Album.coverCrop { x, y, zoom }`；取消写真集编辑不提交。右上重置恢复本次编辑前的封面及取景。裁切只调整显示、不生成副本、不修改原件；缺少裁切参数的旧封面沿用各处原有焦点。在媒体浏览界面直接将另一张图片设为封面时清除原图裁切参数。

## 图片和视频共同浏览（已确认方向）
- 在写真详情点击一项后进入媒体浏览，主区域只展示当前项；紧凑顶部显示返回、写真名、序号/总数及收藏/更多。底部连续缩略图轨道保留四周间距，2026-10-07 用户要求沿用封面选图栏样式：去掉整条底板、外框、阴影及轨道两侧箭头；悬停缩略图原位放大并出现阴影，不显示提示文字，位置与缩放分离。照片和视频共用轨道，视频带播放标识；点击切项，用滚轮和键盘连续滚动，不提供组合式分页跳转栏。大型写真集按可见窗口读取与渲染；主媒体上一项/下一项按钮保持现有行为。
- 按媒体原比例适应可用区域；浅灰留白；窗口模式保留原生标题栏，全屏隐藏。
- 普通窗口的主媒体区域避开顶栏和视频操作栏，缩略图覆盖在媒体上；全屏控件覆盖在媒体上，显示/隐藏不改变图片尺寸；信息面板仅用户主动打开。
- 普通窗口保留顶栏；普通窗口与全屏的缩略图均在鼠标进入底部区域时显示、离开时淡出，键盘聚焦轨道时保持可见；首次进入短暂显示后自动隐藏。减少动态效果时直接切换。全屏下其他控件由移动鼠标或键盘唤起，静止 2 秒后隐藏；焦点位于控件、进度拖动、菜单或面板开启时保持可见。
- 图片支持适应、实际大小、缩放及放大后平移；切换媒体恢复适应，避免沿用上张平移位置。
- 收藏/喜欢/评分与 EXIF 通过按需控件提供。EXIF 仅图片适用；视频显示可得的时长/分辨率等媒体信息。
- 返回详情恢复来源筛选和滚动位置。上一项/下一项遵循进入时可见媒体顺序，不跨写真集。
- 首尾不循环；按钮禁用，键盘不越界。

## 视频原尺寸悬停预览（用户硬要求）
视频位于写真详情媒体网格中。鼠标悬停时必须在**当前卡片原位置、原尺寸**播放，不放大、不浮出、不弹窗，不引起网格重排。

实施默认状态：
| 状态 | 行为 |
|---|---|
| idle | 展示视频封面、播放标识和时长 |
| pending | hover 持续 300ms；移开取消计时，不开始播放 |
| loading | 容器保持稳定，保留封面，必要时显示小加载指示 |
| previewing | 原位播放、静音、循环；不显示完整播放器工具栏 |
| leave | 暂停，复位至起点并恢复封面，释放活动预览资格 |
| error | 保留封面，提示无法预览；允许点击尝试完整播放，不假装成功 |

- 全应用同时最多一个悬停预览；新视频开始前停止旧视频。竞态检查确保旧的异步 play 完成后不会继续播放。
- 离开卡片、滚出视口、页面隐藏、失焦、切换路由时停止预览并清理计时。
- 仅加载需要预览的媒体；不让全部视频自动下载/解码。返回页面不自动恢复预览。
- 点击视频进入完整播放器，不同时保留网格声音或后台播放。预览不写正式播放进度。
- 为避免悬停误触，默认从开头预览；完整播放也从开头开始，后续续播能力另行决定。
- 视频播放标识/时长可常驻，属于必要类型信息，不受写真封面默认隐藏标题规则限制。
- 视频封面默认取前段（短于或等于 10 秒时取开头）；在「设置 → 高级设置 → 视频封面」统一选择前段、中段、后段，自动保存到 `settings.videoPosterPercent`。卡片不提供单独的封面自定义入口；历史逐视频选择保留数据，渲染采用统一设置。图片缓存不写入媒体元数据。
- 预览画面淡入，播放标识切换为动态条形提示，底边显示当前预览进度；减少动态效果时保留静态状态和实际进度。键盘聚焦打开按钮也可预览，离开焦点停止。

## 视频完整播放（本轮设计新增，未有独立定稿图）
- 与图片共用沉浸外壳；点击后开始播放，提供播放/暂停、时间进度、拖动、音量、静音与全屏。
- 默认沿用会话音量，初始 50%；用户主动点击后可有声播放。失败显示可理解的错误，不无限加载。
- 播放结束停在结尾并显示重播，不自动切到下一项。离开播放器停止并释放媒体。
- 图片和视频可在同一序列前后切换，视频切换前先停止。
- 快捷键：图片左右键切项；视频左右键快退/快进 5 秒；Alt+左右统一切媒体；Space 视频播放/暂停；F 全屏；I 信息面板。
- 图片 + / - 缩放，0 适应窗口，1 实际大小。输入框/编辑器不处理这些全局快捷键。
- Esc 依次关闭菜单/信息面板、退出全屏、返回详情；一次只退出一层。
- 控件浮现时明确显示前后媒体按钮与快捷键提示，避免“左右键”语义混淆。

## 通用状态
- 模特目录保持圆头像：鼠标悬停头像时在右侧展开最多三张随机关联写真封面，顶边对齐，同次展开保持稳定，再次进入重新抽取。展开整组占据真实网格空间，其他头像移动或换行；末列空间不足时整组换行，后续头像自动补齐前面空位，收起后恢复原顺序；保留从原头像位置移向封面的鼠标通道。点击封面进入对应写真，返回模特页；点击头像进入模特详情。离开整组、滚动或按 Esc 收起，键盘聚焦模特入口有等价预览并可依次访问封面。预览不记录正式浏览。
- 图片加载中预留原比例空间；坏图有替代占位及重试，避免卡片塌缩。
- 无标签、无模特、无收藏和搜索无结果使用对应 EmptyState，不填造数据。
- 保存失败不清除用户草稿；删除关系不删除磁盘原件。
- 打开媒体失败保留返回和下一项能力；后台扫描/缓存尚未接入时如实标注。

## 文件夹导入与自动资料匹配（2026-10-10）

Prep 的资料提取职责合入 aure 现有导入入口，采用本地确定性规则。用户选择目录后后台逐套保存，无整理页、匹配页或逐套核对步骤；保留磁盘原名，不改写原始媒体和资料文件，不调用外部 API。既有模板规则仅用于兼容读取与导出。

- 创建写真页继续使用「从文件夹导入」系统选择器，可选择单套写真、模特目录或写真总目录。目录有 JSON 或当前层媒体时识别为一套，不向其子目录继续深入；其余目录逐层发现写真，不跟随符号链接或 Windows 重解析点。上限为 8 层、20000 个目录、单套 50000 个媒体。
- 选择目录后使用既有原子事务逐套保存，成功后关闭现有编辑器，单套进入详情，多套留在写真库。选择器取消保留原草稿，不写入记录。扫描或保存失败在现有编辑器反馈实际成功、跳过及失败；保存失败可重试，已成功项不重复提交。关闭保留已保存结果，不报告未读取目录为成功。
- 有效 album.json 优先，缺失时自动提取；损坏、超限、不兼容或引用错误的 JSON 报错，不退回名称猜测。资料文件为 UTF-8，可带 BOM，最多 1 MiB。必填 version: 1 与非空字符串 name；number 为保留前导零的字符串；models、tags 为不重复的非空名称数组；cover 为同层图片文件名；media 为同层完整媒体有序清单。不接受未知字段。
- JSON 引用按字面文件名匹配，英文大小写兼容，不含路径分隔符、盘符或目录跳转。非空 media 必须覆盖当前层全部支持媒体；缺失、重复或不受支持项报错。有 JSON 但省略 media 时保留原字典序；无 JSON 使用数字自然排序。所有入口统一照片在前、视频在后，各类型内保留顺序。
- 无 JSON 时只提取明确的 NO、VOL 或第 N 期等编号标记，不把日期、文件序号或数量当编号。移除已确认的前置模特文本、唯一编号标记和明确数量体积块形成名称；不能可靠拆分时保留原名，原始名称另存。
- 模特按规范化名称或完整别名唯一匹配，不模糊匹配。编号前的文本为人物证据，编号后的角色标题不自动建为模特；已知父目录可辅助识别。新人物要求父目录与编号前的完整人物文本相互印证；网盘、下载、合集等容器名排除。同名或别名歧义、父目录与人物文本冲突时留空，不阻塞有效媒体导入。
- 无 JSON 的标签只匹配已有标签词表中的明确文本，不推断内容。有 JSON 时可按明确名称创建标签；同名歧义跳过关联，其他资料不覆盖。新标签仍归入「导入标签」。
- 封面优先有效 JSON 设置，其次 cover.*，最后读取顺序中的第一张图片；纯视频可无封面。实际数量和大小来自磁盘扫描，名称标注仅作参考。封面修改复用现有编辑器与缩略图轨道，不新增箭头、文字提示或横向分页栏。
- 每套记录规则版本、原文、字段来源及未确定原因；手动修改标记该字段由用户所有。重复来源目录复用已有记录、跳过保存，不重新解析或覆盖修改。不同目录不能凭名称、编号或模特相同而合并。
- 写入及关联在数据适配层提交，不能用分页快照覆盖整库；媒体保持稳定 ID 和现有原生协议。浏览器验证只覆盖模拟调用，真实选择器及文件访问以隔离 identifier 的 Windows Tauri/WebView2 验证为准，正式图库验收只读。
