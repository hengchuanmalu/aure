基线 3.1 · 2026-09-28。数值为镜集实施默认，不是个人母系统的全局审美结论。CSS 变量来源为 [tokens.css](../tokens/tokens.css)，shadcn 语义主题在 `src/styles/foundation.css`，分区样式在 `src/styles/`。

## 设计依据
- 已确认的 PREF-001：功能图标统一采用 Lucide。24 单位网格、2px 描边与收藏填充为项目实施默认，并非永久个人 Token。
- UI-004 用于窄侧栏的图标加文字、发现页左大右小焦点网格、头像筛选；UI-003 用于可手动切换的图集展台；UI-002 用于克制背景与留白分区。这些是本项目的案例应用，不将候选规则写回已确认偏好。
- 延续圆形模特头像、统一资料编辑、单媒体沉浸浏览、封面悬停/键盘聚焦显示操作等既有交互。

- 母系统 UIP-001：React / Windows Web-Tech 采用 shadcn/ui + Lucide，Fluent 仅为 Windows 行为参考。此次将全局控件改为中性色，保留系统标题栏与键鼠操作。具体色值、圆角和密度是可逆的项目实施选择。

## 组件来源与维护
- 2026-09-28 按 [官方 Vite 接入文档](https://ui.shadcn.com/docs/installation/vite) 配置现有工程，通过官方 CLI 按需添加 Button、Input、Textarea、Checkbox、Switch、Dialog、AlertDialog、DropdownMenu、Label、NativeSelect；配置见 `components.json`，源码见 `src/components/ui/`。shadcn/ui、Radix UI、Tailwind CSS 均采用 MIT 许可证；具体安装版本以锁文件为准。
- 本地定制：按钮只过渡颜色/边框/阴影；项目组合组件集中于 `src/ui/`；语义色由图库 Token 映射。官方组件后续更新需审阅差异，不用覆盖命令抹除定制。
- UI 控件迁移不改变 Repository、业务操作和媒体资源；图库/媒体布局仍为领域组件。媒体时间轴及裁切焦点保留原生 range，以保留浏览器键盘语义与直接数值控制。
- 模态与确认采用 Radix 焦点管理，关闭恢复触发按钮；确认关闭草稿使用 AlertDialog；全局搜索快捷键在弹窗打开时暂停。

## Shell 与响应式
- 默认桌面窗口 1440×960，最小 1024×720。效果图 1536×1024 是参考画布，不应被整图等比缩放来代替布局。
- 采用系统原生窗口边框/控制按钮，不在 Web 内容重复绘制一组窗口按钮。
- Sidebar 默认 72px；小于 1200px 为 68px，均保留图标下方文字。设置置底。
- TopBar 约 58px；包含位置提示、全局搜索（Ctrl+K）和创建入口。主区域左右留白 24–28px；内容区以间距分区。
- 轨道横滚限定于轨道容器，页面主体仅纵向滚动；不产生整页横向溢出。
- 写真库默认叠放网格，桌面四列、较窄窗口三列；可切换竖幅封面网格，展示方式通过 URL 保留。模特详情的关联写真集沿用相同切换控件与卡片变形动画，刷新、进入写真后返回保留展示方式，切换保留当前浏览位置；系统或应用减少动效时直接切换。模特网格列最小宽 160px，头像 96px，紧凑时 88px。
- 发现页焦点网格左侧跨两行，右侧四张辅助封面；不足三项时使用单行布局。头像筛选作用于焦点网格和图集展台，最近更新/收藏/历史仍为全库视图。
- 堆叠卡片的横向浏览统一采用「最近更新」同款原生平滑滚动，保留连续轨道和卡片节点；减少动态效果时直接定位。图集展台每次滚动一整组（最多四本），末组显示剩余内容，不循环、不自动播放；首尾按钮禁用，筛选改变后回到第一组。
- 最近更新、最近浏览隐藏底部横向滚动条，保留箭头及触控板横向浏览。图集展台右上角与最近更新统一为「查看全部、左箭头、右箭头」，沿用相同样式与间距，不显示页码；查看全部进入当前模特筛选下的写真库。
- 写真详情使用左封面、右资料；人物详情使用左资料、右背景。资料独立排版，长文自然增长，小窗口上下排列。
- 写真详情的编辑入口放在顶部右侧；收藏采用封面右上角的心形按钮；浏览写真放在资料区右下角。资料区不再保留左下角的编辑、收藏和浏览按钮组（2026-10-06 用户截图要求）。
- 模特背景固定 16:9，详情页背景宽度不超过 720px，高度由比例确定；编辑裁切与页面效果使用同一比例，不随弹窗拉伸。背景按显示尺寸、设备像素比、裁切倍率和原图比例选择 1024/2048/3072px 长边的缓存预览（JPEG 92），不放大低分辨率原件；列表继续用 512px。各档缓存区分尺寸，复用授权、并发限制及 512MB 缓存预算。
- 发现页推荐封面、图集展台、最近更新/浏览、收藏轨道和标签封面采用同样的自适应高清缓存（最高长边 3072px），只加载可见及近视口图片；小头像和其他页面列表保持轻量加载。发现页推荐不再直接解码完整原图，沉浸浏览继续使用原图。
- 写真详情的媒体区支持瀑布流、平铺与自适应三种视图，以及每行 1–10 张。瀑布流使用等宽列并保留比例；平铺使用统一方形裁切；自适应完整行按所选数量排列并保持比例，末行不拉大。视图与数量作为独立显示偏好保留，不写入图库资料。布局切换短暂移动和调整卡片尺寸，不缩放视频内容；重排前结束悬停播放，减少动态效果时直接切换。
- 写真详情工具栏左侧是媒体筛选，右侧是数量滑杆和三个纯图标视图按钮；视图名称仅在悬停或键盘聚焦时提示。不显示“张/行”文案或批量选择入口；多页内容的翻页箭头放在媒体列表底部，不显示页码、总项数或跳转输入框。
- 仅原本已有的悬停说明使用 `HoverHint`：白底黑字、紧凑圆角和柔和阴影，无箭头；紧贴控件下方居中，窗口边缘自动避让。原生 `title` 文件名提示和既有媒体视图提示使用同一组件；不根据无障碍名称自动新增提示，侧栏与原本无提示的按钮不新增提示。封面底部缩略图栏仍遵循已确认的无文字提示规则。
- 未经用户明确允许，不新增或重新引入“上一页 / 页码与总项数 / 下一页 / 跳至输入框”组合式横向分页跳转栏（PREF-002，2026-10-06）。头像照片使用有界虚拟滚动，外层编辑区隐藏滚动条；预览区滚轮调整缩放，不滚动外层正文。底部不显示裁切操作说明文字。
- 写真编辑、模特编辑、批量导入共用 1280px 宽度，加载、错误与各分区保持同一宽度；标签、分组和确认弹窗共用 600px 紧凑宽度。实际宽度不超过窗口宽度减去共享边距：桌面 48px，窗口不宽于 760px 时 24px。宽度与边距集中在共享 Token，页面不重复定义；最大高度适应窗口，正文独立滚动、底部保存栏保持可见。
- 统一紧凑栏标准（2026-10-05）：用户要求“上下两边的页面太厚了，变窄些，确定下来，以后所有的界面就按这个标准搞”。本项目所有同类编辑、创建界面的标题栏与底部操作栏沿用共享 Token：普通标题栏 48px、操作栏 56px、栏内按钮 32px、标题 18px；左右内边距桌面 24px、窄屏 20px。长标题、错误提示或按钮换行时允许按内容增高，正文保持独立滚动；不再为单个编辑器另设厚重的上下留白。这些数值是本次项目实施标准，不扩展为其他项目的个人全局 Token。
- 弹窗标题区域下方及底部操作区域上方不使用横向分界线（2026-10-08 用户明确要求，母系统 PREF-007）；适用于全应用编辑、创建、选择和确认弹窗，以留白组织区域。
- 写真集创建与编辑按 2026-10-08 指定参考图采用两个并列白底圆角面板，以轻边框和间距区分。左侧为封面标题、空态说明及虚线选图区；右侧为写真信息、右上角导入入口、名称、对齐的编号/标签栏和关联模特。空封面不铺灰底；有图时保留原比例与封面取景、悬停选图。正文固定，关联模特及展开的标签长列表分别局部纵向滚动，操作栏保持可见。
- 写真集内的「选择标签」向下展开白底分组列表，每个标签独占一行，点击整行切换选择，以浅底和字重表达选中状态，不使用勾选框或横排胶囊可选项。展开与收回沿用共享高度/透明度过渡及箭头转动，退出期间禁止操作并恢复焦点，减少动态效果时直接切换。长列表在局部纵向滚动，收起保留草稿选择，保存时统一提交。
- 使用中文真实文本衡量宽度；长标题限制摘要行数并提供完整可访问名称，长字段换行。

## 图片与动效
- 所有排序控件沿用统一菜单：仅当前排序项右侧显示一枚 Lucide 方向箭头，升序向上、降序向下；点击当前整项一次切换方向，不设独立箭头按钮、不显示对勾。切换时箭头以中心为轴顺时针转动半圈，菜单保持打开以呈现反馈；减少动态效果时直接切换方向。日期默认降序、名称默认升序；排序字段与方向写入来源 URL，连续加载沿用同一顺序。
- Cover 使用 cover 裁切，允许配置焦点；观看使用 contain；不拉伸图片、视频或头像。
- AlbumCard 外框不缩放；叠放叶片在卡片内部展开，封面模式仅图片轻微放大且不挤动邻居；**视频媒体卡禁止缩放**，预览沿用完全相同的容器。
- CSS 负责 hover/active；Motion 用于面板/弹窗/页面状态切换；同一属性由一种方式控制。
- 只为有反馈意义的变化做动画，优先 transform/opacity，不使用 transition: all，不逐帧写 React state。
- 发现页推荐区按用户 2026-10-07 要求保持一大四小、五张整组轮换：默认停留 6 秒，下一组封面解码完成后进行 800ms 交叉淡入与轻微缩放归位；只保留当前和待切换两组。推荐标题栏右侧仅保留刷新图标用于手动换组，图片上不放切换控件。自动轮换开关、切换间隔（3–60 秒）、过渡速度和悬停暂停集中在「设置 → 高级设置」，减少动态效果及视频封面等偏好也归入该分类，自动保存。聚焦、菜单打开、页面不可见或窗口失焦时暂停；减少动态效果时停用自动轮换，手动直接切换。模特筛选改变时回到首组，空组及单张不轮换。不让大图持续缩放、不做磁吸按钮/长入场动画/滚动劫持。
- 系统减少动态效果或应用减少动效开启时取消位移/缩放，保留必要的颜色反馈。
- 所有 hover 操作同时有 focus-visible 等价路径；图标按钮有中文可访问名称，焦点不因动画丢失。

## 视频参考的布局与动效应用 · 2026-09-28
- 依据：用户提供的 `TwitterSaver.Net_unN_P5kZraHpg836_1080p.mp4`（21.43 秒）。观察到窄导航、紧凑工具区、头像分类条、多张封面叠放、悬停展开和分类内容切换；只复用布局/交互机制，不使用视频里的品牌与图片。

- 叠放仅从当前图集有效媒体提取最多四张不同的预览，视频使用 poster；没有预览时仅显示真实封面，不重复素材伪造层数。

## 按场景选择动效 · 2026-10-07

依据已确认的 PREF-003/004：图片保持注意力中心，指定辅助栏按需淡变。下面是 aure 的可逆实施方案，不把候选方案或毫秒值升级为个人全局偏好。规范在此完整说明，公开仓库不依赖本机个人设计档案。

- 导航返回、连续搜索/切图、虚拟列表挂载直接显示；写真卡片不逐项入场、不对整库做 layout 测量。保留浏览位置和实体身份（M-08/10/13/16/21）。
- 按钮即时执行并局部变色；保留既有模特筛选底块、筛选面板和标签展开。设置分区使用 Motion Primitives 的 Transition Panel，局部 200ms 透明度与 6px 归位。模特编辑的六个分区保持同一弹窗宽度，内容仅淡变，并按当前分区的实际高度做 200ms 过渡，不缩放文字或裁切图片；普通旧分区 100ms 退出并立即 inert，头像/背景编辑切换时旧分区立即退出以免图片重影。模特编辑的选中底块只在导航栏内部按位置和宽度过渡，避免弹窗高度变化干扰共享布局坐标；其他同组点击选中底块复用 Animated Background，不用于侧栏 hover。复选标记复用 tw-animate-css 的淡入与缩放，开关滑块使用 220ms 归位。以上为 2026-10-09 当前要求下的项目实施值。
