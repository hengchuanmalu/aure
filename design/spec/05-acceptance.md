# 开发验收清单
以下是产品验收要求，勾选项不代表本次运行结果。底部资源整理是历史设计验收；大规模图库的性能边界及测试区分见 [大规模本地图库](06-large-library.md)。

## 视觉与布局
- [ ] 所有页面命名统一“模特”；没有旧“模特档案”导航。
- [ ] Windows 1024×720、1440×960、1920×1080，缩放 100%/125%/150% 下无整页横向溢出。
- [ ] 图片是主体，无后台统计卡；封面 3:2、模特小头像正圆。
- [ ] 轨道边缘自然，hover 不裁切，焦点轮廓可见，文字对比与层级清晰。
- [ ] 长中文标题、长简介、多标签不会压住操作按钮或主视觉人物。
- [ ] 系统减少动态效果生效，禁用长入场及滚动劫持。

## 模特定稿规则
- [ ] 列表展示不同模特，头像可进入对应详情。
- [ ] 资料位于左上 Hero；没有下方横排人物事实栏或“浏览写真集”按钮。
- [ ] 背景/头像可独立更改；仅“编辑资料”提供修改入口。
- [ ] 编辑器跨分区共享草稿；增删改排序字段、链接、档案照片和写真关联可统一保存。
- [ ] 取消不落库、失败保留草稿、重启后已保存信息仍在。
- [ ] 详情及关联页面立即反映保存结果，人数及写真数来自关系数据。

## 混合媒体
- [ ] 图片/视频混排，计数、标识和时长正确。
- [ ] 在卡片上不足 300ms 不触发预览；300ms 后原位静音播放。
- [ ] 悬停前后卡片边界尺寸与邻居位置不变，无 scale 放大。
- [ ] 迅速划过多个视频、滚出视口、离开窗口/页面后，最多一个视频活动且无后台漏播。
- [ ] 移开停止并恢复 poster；慢加载返回的旧 play 请求不会重新启动。
- [ ] 批量模式点击只选择，不打开或自动预览。
- [ ] 点击打开完整视频可播放、暂停、seek、调音量、全屏；退出后声音停止。
- [ ] 图片/视频连续切换、边界、加载失败均可恢复，操作不锁死。
- [ ] 实际解码样本记录容器/视频编码/音频编码；至少一种视频样本真实播放通过。

## 沉浸浏览
- [ ] 默认只显示当前媒体，无常驻缩略图、EXIF 或应用工具栏。
- [ ] 横图/竖图都按原比例 contain；缩放/实际大小正常。
- [ ] 临时工具栏不挤压媒体；操作中不自动消失。
- [ ] Esc 层级、图片与视频快捷键无冲突；输入框不误触。
- [ ] 返回后保留详情滚动和筛选；最近浏览不被 hover 预览污染。

## 数据与完整流程
- [ ] 写真创建编辑、搜索筛选、批量 Tag、收藏、喜欢、评分跨页面一致。
- [ ] 删除标签/关系不删除媒体原件；EXIF 缺失显示未知。
- [ ] 空库、空结果、缺图、失效路径、保存失败、视频不支持均有明确反馈。
- [ ] mock 真实可编辑并持久化；未接入扫描/SQLite 不显示虚假完成。
- [ ] TypeScript、前端生产构建、Rust 检查通过。
- [ ] 浏览器验证后启动真实 Tauri 窗口复核，不仅用浏览器截图替代桌面验收。

## 运行环境与发行验收

此表记录支持目标和验证边界，不是测试结果。现有本机更新、原生测试脚本与 CI 构建不能替代干净电脑验收；本次结果须注明系统、架构、WebView2 版本、FFmpeg 状态、硬件与磁盘条件。

| 环境 / 场景 | 已有机制或目标 | 待验证的行为 |
| --- | --- | --- |
| Windows 10 22H2 / Windows 11 x64 | 当前本机更新为 x64；以当前 Evergreen WebView2 为兼容目标 | 干净标准用户首次启动、导入、浏览、编辑保存与重启。 |
| 缺少或过旧的 WebView2；离线首装 | NSIS 安装版缺失或低于 111 时尝试联网安装或更新 Runtime；直接运行版需预先安装。本机更新仍只检测，不安装 Runtime | 面向其他电脑的在线/离线首装分别验收；配置不代替真实启动，当前 Evergreen 仍为兼容目标。 |
| 有 / 无 FFmpeg 与 ffprobe | 工具可选，不随应用分发；缺少 ffprobe 时尝试原视频 | 常规尺寸的常见图片不受影响；AVIF、超大 JPEG、视频封面、信息与兼容副本缺依赖时说明原因；验证 H.264 / HEVC、可取消与原件不变。 |
| 原件只读；数据 / 缓存目录受限；磁盘空间不足 | 引用导入，SQLite 与缓存写入当前用户目录 | 原件只读仍可浏览；应用目录不能写或空间不足时说明原因、保留元数据和草稿，不崩溃或显示成功。 |
| 中文 / Unicode、超过 260 字符、UNC、移动磁盘重连与盘符改变 | 已有规范路径、精确授权、缺失重关联与目录重新定位 | 真实文件导入、缩略图、Range 播放和重新授权；不能只检查路径字符串。 |
| 云占位文件、链接 / 重解析点 | 扫描当前排除重解析点，云文件应先落地 | 区分文件不可用与不支持的目录；避免静默漏导，不自动下载原件。 |
| 低配置与高缩放屏幕 | 当前窗口最小逻辑尺寸 1024×720；性能预算见 [大规模本地图库](06-large-library.md) | 1366×768 等屏幕在 125% / 150% 缩放、低内存与慢磁盘下的布局、交互、冷启动和缓存生成；浏览器视口测试不能替代系统 DPI。 |
| ARM64、32 位、Windows 7 / 8.1 | 不在当前验收范围，无相应发行产物 | 如扩大支持范围，另建构建与运行矩阵；不要将 x64 产物或框架可编译当作兼容证明。 |

- [ ] 分发包先在没有 Node、Rust 和开发工具的干净电脑验证；应用使用者不承担开发依赖。
- [ ] 分开报告前端构建、Rust 测试、浏览器交互、已安装 WebView2 和干净电脑运行，不把其中一层的通过写成全部通过。
- [ ] 新增运行依赖说明联网要求、体积与降级；按使用环境选择在线引导或离线方案，不为少数可选格式强制扩大所有用户的基础包。
- [ ] 正式图库验收只读；写入、权限故障与恢复测试使用独立 identifier 和可丢弃数据。修复后覆盖同机制受影响的场景。
- [ ] 媒体工具运行或任务排队时正常关闭应用，取消或完成在途任务后清理暂存文件，再结束应用进程；没有孤儿 FFmpeg/ffprobe。启动新的应用进程后，已保存资料和基本页面仍可用，原件不变。页面重载、真冷重启与启动耗时分开验证；退出/启动行为通过不代表低内存、慢磁盘或冷启动性能已验收。独立退出用例及素材要求见贡献指南。
- [ ] 每个发行候选固定源码指纹、EXE SHA-256、前端入口和测试环境；任何源码变动后重跑受影响层次。自动入口与命令见 [贡献指南](../../CONTRIBUTING.md#发行前验证)。
- [ ] 分开保留自动 gate、人工环境矩阵和未执行项。全测试以实际风险覆盖为标准；历史诊断脚本不自动并入发行 gate，旧截图和旧报告不作为本次证据。
- [ ] npm/RustSec 检查同时记录漏洞与维护/撤回/unsound 告警、实际目标平台的依赖链和处置；资源来源及许可证检查通过，二进制分发前核对实际链接依赖的许可全文。
- [ ] 升级过程中保留即时前版本，测试替换前校验失败、程序占用、首次安装无备份与备份轮转；回滚测试在可丢弃安装目录和数据库完成，原件及既有图库不变。程序备份不能代替数据库备份，跨结构版本降级须另验兼容性。

环境依据：[Microsoft WebView2 分发](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)、[Microsoft 当前系统支持](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-supported-operating-systems)、[Tauri Windows 安装与架构](https://v2.tauri.app/distribute/windows-installer/)、[Tailwind CSS 兼容说明](https://tailwindcss.com/docs/compatibility)。运行依赖要求变化时重新核查；Windows 系统版本、WebView2 版本与应用实际验收分别记录。
